Implementation guardrails

  • Use one shared token source; SPA.CZ is a semantic colour skin, not per-screen colour overrides.
  • Use Outfit for headings and DM Sans for body/interface text; do not inherit the legacy extranet Poppins declaration.
  • Apply density only through the global 0.70 mapping. Preserve control heights and touch targets.
  • Keep matrices horizontally scrollable with sticky header and descriptor column.
  • Do not introduce desktop web navigation, desktop sidebars or desktop screen specifications into this mobile artifact.
